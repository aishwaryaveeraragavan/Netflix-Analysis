## 📌 Project Overview

This project presents an interactive **Netflix Data Analysis Dashboard built using Microsoft Power BI**. The dashboard explores Netflix movies and TV shows to uncover insights into content distribution, genres, ratings, countries, and release trends.

Using data visualization and interactive reporting, this project transforms raw Netflix data into meaningful insights that help users understand the composition and trends of Netflix's content library.

## 🎯 Project Objectives

- Analyze the distribution of movies and TV shows on Netflix.
- Identify the most popular genres and content categories.
- Explore the contribution of different countries to Netflix's content library.
- Analyze content ratings and their distribution.
- Understand trends in content releases over the years.
- Build an interactive dashboard to present insights clearly and effectively.

## 🛠️ Tools and Technologies

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and analytical calculations, where applicable
- **Data Modeling** – Organizing data for effective analysis, where applicable

## 📂 Dataset Description

The project uses a Netflix movies and TV shows dataset containing information about titles available on the platform.
